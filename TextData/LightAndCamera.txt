A 3D scene in Unity is a virtual environment consisting of 3D objects, lighting, cameras, materials, and
physics components. Unity provides several built-in 3D objects such as Cubes, Spheres, Capsules,
Planes, and Terrain that can be combined to create interactive environments. The Main Camera acts as
the player's viewpoint. It captures everything visible in the scene and displays it in the Game window.
Camera movement can be controlled through C# scripts using keyboard and mouse input.
Lighting is one of the most important aspects of 3D game development. It improves realism and visual
quality by simulating natural or artificial light. Unity provides different types of lights:
• Directional Light
• Point Light
• Spot Light
• Area Light (HDRP)
Directional Light simulates sunlight and is commonly used in outdoor environments.
Camera controls allow users to navigate through the 3D environment. The camera can move forward,
backward, left, right, upward, and downward using keyboard inputs while the mouse can rotate the
camera to look around.
Implementing lighting and camera controls helps developers create immersive and interactive 3D game
environments.

Steps:
1. Create the 3D Scene
1. Open Unity and create a 3D project.
2. In the Hierarchy, right-click → 3D Object → Plane.
3. Rename it Ground.
4. Right-click → 3D Object → Capsule.
5. Rename it Player.
6. Set Player Position to (0, 1, 0).


2. Add Lighting
1. In the Hierarchy, right-click → Light → Directional Light.
2. Rename it Directional Light.
3. Set Rotation to (50, -30, 0).
4. Adjust Intensity to around 1.

3. Set Up Camera
1. Select Main Camera.
2. Set Position to (0, 5, -8).
3. Set Rotation to (25, 0, 0).
4. This gives you a view of the player and ground.


4. Add Rigidbody to Player
1. Select Player.
2. Inspector → Add Component → Rigidbody.
3. Enable Use Gravity.
4. Keep Is Kinematic disabled.
5. Freeze Rotation X and Z if you want the capsule to remain upright.


5. Create Player Movement Script
1. In Project window, right-click → Create → C# Script.
2. Name it PlayerMovement.
3. Attach it to Player.
4. Add this code:

using UnityEngine;

public class PlayerMovement : MonoBehaviour
{
    private Rigidbody rb;

    public float speed = 5f;

    void Start()
    {
        rb = GetComponent<Rigidbody>();
    }

    void FixedUpdate()
    {
        float x = Input.GetAxis("Horizontal");
        float z = Input.GetAxis("Vertical");

        Vector3 movement = new Vector3(x, 0, z);

        rb.MovePosition(
            rb.position + movement.normalized * speed * Time.fixedDeltaTime
        );
    }
}
This uses Unity's traditional Input Manager. If your project is configured for the New Input System only, set Active Input Handling to Both or use the New Input System instead.

6. Test the Game
1. Press Play.
2. Use W, A, S, D or arrow keys.
3. Player moves around the plane.
4. Camera remains fixed.
5. Directional Light illuminates the scene.
